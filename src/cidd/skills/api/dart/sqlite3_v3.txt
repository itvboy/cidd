DATABASE API REFERENCE:

1. Execute SQL:
   database.execute(sql, parameters);

2. Query rows:
   final rows = database.select(sql, parameters);
   - Returns a ResultSet.
   - Use rows.isEmpty, rows.first or iterate over rows.
   - Access row values by column name.

3. Prepared statements:
   final statement = database.prepare(sql);
   try {
     statement.execute(parameters);
   } finally {
     statement.close();
   }

4. Retrieve the last inserted row ID:
   final id = database.lastInsertRowId;
   - Read immediately after a successful INSERT on the same Database.

5. Retrieve the number of affected rows:
   final count = database.updatedRows;
   - Read immediately after the corresponding UPDATE or DELETE.
   - Use count > 0 when the contract requires a boolean success result.

6. Schema initialization:
   database.execute(createTableSql);
   - createTableSql must use CREATE TABLE IF NOT EXISTS.
   - Use SQLite-compatible column types.
   - Do not drop or recreate existing tables.

7. Boolean persistence:
   - Persist boolean values as integers 0 or 1.
   - Convert stored integers back to Dart bool when reading.

ALLOWED DATABASE MEMBERS:
- Database.execute(...)
- Database.select(...)
- Database.prepare(...)
- Database.lastInsertRowId
- Database.updatedRows

ALLOWED PREPARED STATEMENT MEMBERS:
- PreparedStatement.execute(...)
- PreparedStatement.close()

- database.getLastInsertRowId()
